# SortMedication

A simple web page for keeping track of the medications you have on hand.

You can:

- Add a medication with its name, dose, quantity, expiry date and restock level
- Use the − and + buttons to change the quantity as you use or buy more
- Sort the list by name or by expiry date
- See at a glance what is low on stock, expiring within 30 days, or already expired

## How to open it

There is nothing to install.

1. Download this repository (on GitHub, click the green **Code** button, then **Download ZIP**, and unzip it).
2. Double-click `index.html`. It opens in your web browser.

Your list is saved in that browser on that computer. If you open the page in a
different browser or on another computer, it starts empty there.

## The files

- `index.html` is the page layout: the form and the table.
- `style.css` controls how it looks: colours, spacing, fonts.
- `app.js` is the behaviour: saving, sorting, and working out the warnings.
